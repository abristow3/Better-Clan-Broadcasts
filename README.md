# Better Clan Broadcasts
A plugin that prepends clan member rank icons to clan broadcasts.

It works for:
- Quest Complete broadcasts
- Achievement Diary broadcasts
- Speed Time broadcasts
- Collection log broadcasts
- Level up broadcasts
- XP milestone broadcasts
- Total level broadcasts
- Pet broadcasts
- Combat Diary completions (also prepends ironman icons for these)
